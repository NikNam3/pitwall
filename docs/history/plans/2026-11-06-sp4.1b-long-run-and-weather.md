# SP4.1b Long Run and Weather Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this repo every task has two phases by two agents (contract C82): a test agent writes the failing tests and commits them, an implementation agent makes them pass without touching them. Supervisor steps (marked **supervisor**) commit contract-first types (C81), stubs, data files and gates, and write no logic.

**Goal:** Four long-run and weather judgements (`raising-average`, `lap-overview`, `weather` over a new `rain-outlook` calculator, `crossover`) with their displays in the `garage` workbook; `race-moment`'s rain rule moves onto `rain-outlook`; the R20 `battle.segments` slowness is fixed; screenshot baselines stay at 58.

**Architecture:** Five quick units over the projection, live state and `pit-loss`'s output, each on cadence `frame` (it runs only on frames one of its declared reads changed). Track status and green laps come from recorded lap facts (`scShare`, `vscShare`) and the projection's `membershipOf` through behaviour tables over the session-phase machines (C26, C44). `rain-outlook` is the one rain judgement (C43), read by `weather` and `race-moment`. Displays render topic values (C65).

**Tech Stack:** TypeScript (Node type stripping), pnpm monorepo, vitest + fast-check, Svelte 5, Playwright.

**Spec:** `docs/specs/2026-11-06-sp4.1b-long-run-and-weather-design.md` (reviewed by the user, 2026-11-06). The contract `docs/architecture.md`; mockups `docs/design/2026-10-30-sp4a-displays/4-longrun.html`, `5-weather.html`.

## Review Focus

1. **A dry race:** `crossover` has no inter or wet lap at all: `firstFaster` and `payback` `notApplicable`, `byLap` medians `insufficientData` for both, never a division by zero. → Task 5 row 6.
2. **The first laps of a session** (no `forPace` lap yet; lap 1 of a race is never one): `raising-average` gives an empty curve, `crossover.dryRefMs` `insufficientData`, `lap-overview` heat `notApplicable`. → Task 3 row 3, Task 4 row 4, Task 5 row 2.
3. **A provisional lap superseded by its confirmed record** with a different time: every unit counts the lap once, with the confirmed time (C25). → Task 3 row 4, Task 4 row 7, Task 5 row 8.
4. **A flashback mid-stint:** outputs equal those of a run without the undone laps (C33); covered by the generic incremental-rewind and determinism properties once the units are registered. → Task 1 step 3 (registration), Task 15 gates.
5. **A forecast with samples out of time order or none after now:** `rain-outlook` reads them sorted by `offsetMin`, ignores `offsetMin < 0`; `race-moment`'s moment is unchanged against today's rule. → Task 2 row 3, Task 8 row 2.
6. **A restart lap** with a sliver of SC (below `maxNeutralisedMs`): green in `lap-overview` and in `crossover` (one rule, C43). → Task 4 row 5, Task 5 row 8, Task 13 step 3.
7. **Our tyre switch:** `firstFaster` is searched against our current type (B9). → Task 5 row 5a.
