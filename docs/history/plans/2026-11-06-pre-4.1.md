# Pre-4.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this repo every task has two phases by two agents (contract C82): a test agent writes the failing tests and commits them, an implementation agent makes them pass without touching them. Supervisor steps (marked **supervisor**) commit the contract, scripts and gates, and write no logic.

**Goal:** Every live session writes a track sidecar (a not-applicable one too), the panels of a window can be added and removed in an edit mode without the palette, and `pnpm desktop` regenerates the indexes before it builds the UI.

**Architecture:** C62b's text changes first (C0). The bridge's session file writer always writes `<recording>.track.json`; the loader reads a not-applicable sidecar as `notApplicable`. The shell gains a window-local edit mode: a top-bar toggle and command, a `+` per dock group that opens the palette on the add commands, and a `×` per panel header that runs a per-panel remove command; the dock's change is saved through the existing `workbook.updateWindow`.

**Tech Stack:** TypeScript (Node type stripping), pnpm monorepo, vitest, Svelte 5, dockview-core.

**Spec:** `docs/superpowers/specs/2026-11-06-pre-4.1-design.md` (approved by the user, 2026-11-06, with the go for the run). The contract `docs/architecture.md`.

- Edit mode is window-local (C73): off at start and after a reload, never sent to the bridge, never in a workbook file.

## Review Focus

1. **A recording written by 4.0 for a track without a file** has no sidecar at all: its replay still loads the committed file (unchanged rule for "without any sidecar"). → Task 1 row 4.
2. **A not-applicable sidecar next to a recording of a track that later gets a committed file**: the replay stays `notApplicable` and logs nothing. → Task 1 rows 2 and 3.
3. **Removing the panel that is the window's last one**: the window becomes empty, the bridge receives a window with no panels, and the empty-window picker shows as today. → Task 2 row 6.
4. **Clicking `+` on a group that is not the active one**: the panel lands in the clicked group, not in the previously active one. → Task 2 row 5.
5. **Pressing a removed panel's `panel.remove.<id>` key binding from `keys.json` after edit mode is switched off**: the command is not in the registry, so nothing happens. → Task 2 row 3.
