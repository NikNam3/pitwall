1No data yet / doesn't apply: a dim dash —. HAM hasn't completed a lap since the pit stop. Also the leader's gap. Never a 0 and never a blank.
2Hidden by the game: a human rival with private telemetry. A dim short word priv, so you know it's not missing but withheld.
3Estimated, not measured: pitwall's own estimate (here NOR's wear from tyre age and lap times) gets a ~ and a slightly dimmer grey. Matters for strategy: you always know what's measured and what's guessed.
4Inactive car (DNF, DSQ, retired): the whole row goes dim with the reason; it stays at the bottom so the order doesn't jump.
5Stale: the data stopped arriving. Values stay visible but go dim, and the header says stale 6 s in amber. Stale is wrong, so it earns a highlight, but only once, in the header, not on every number.
6Errored: a calculation failed. The widget shows one sentence instead of numbers, with the header marked red. It never shows old or made-up numbers.
