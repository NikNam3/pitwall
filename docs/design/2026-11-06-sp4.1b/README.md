## Questions

### Q1. Which role colours the red status in the strip?

A lap completed under a red flag gets status `red` (spec 3.2). The strip under the grid already marks VSC/SC laps in yellow. The theme has a `flagRed` role.

- **A (drawn):** the word `red` (full) and the bar `━` (compact) in `flagRed`.
- **B:** `critical`: the alarm colour, but a red-flag lap is information, not an alarm.
- **C:** no colour, the word only; the strip then looks the same as a grey note.

Recommendation: A. `flagRed` is the flag's own colour, and the strip is a flag strip.

### Q2. How are the rivals chosen?

The raising average draws up to three rivals (spec 4). The panel must let the user name them without a new kind of control.

- **A (drawn):** three `carOption`s `rival1` to `rival3`, the existing kit option, each a select in the settings popover. Consequence: no new kit piece; a panel's options are saved with its window in the workbook.
- **B:** one multi-select option. Consequence: a new option kind in the kit and the popover.
- **C:** rivals follow the link group's other cars. Consequence: no options, but one link group fixes the rivals of every linked panel.

### Q3. What does an unset rival picker offer, and which cars does it list?

The existing `carOption` select offers `follow` (the panel's link), `player`, `teammate`, and the current number. `follow` has no meaning for a rival, and a plain car code list is needed to pick HAM.

- **A (drawn):** the first choice reads `none` (no line), then the session's cars by code. Consequence: the select's text depends on the option; `carOption` gets a label for its unset choice and the popover lists the cars (the session's car codes from `cars.overview`, which the panel already subscribes to).
- **B:** keep `follow`, `player`, `teammate` as they are and add the cars below them. Consequence: `follow` for a rival would mean "the link's car", which duplicates our own line.

Recommendation: A.

### Q4. Is the lap overview's full size 84×8?

The sample's second stint-1 row (L11 to L15) now carries a red strip as well, so the grid needs one more row than the original 84×7. A worst case (strips under every row) is more still.

- **A (drawn):** 84×8 for the sample; the display's minimum stays 84×7, and a strip row that does not fit is dropped before the lap row is (the strip is the cheaper loss).
- **B:** raise the full size to 84×10, enough for strips under every row of two stints. Consequence: it needs more of the workbook's room all the time.
- **C:** put the strip into the lap cell itself (the time in `flagRed` or `flagYellow`) and drop the strip rows. Consequence: no extra rows, but the heat background and the colour then compete.
