- **Badge:** `ᶜ` replaces `ˢ` everywhere; the source words become `session`, `calibration`, `default` (the pit-loss SOURCE column widens from 8 to 11 within its 32 cells). The compounds table puts the badge after DEG/LAP.

## Questions

### Q1. Which value does a source row show?

Each priors entry has a per-source value and residual (`calibration.values`), but a row has room for one or two numbers. The drawing shows degradation's.

- **A (drawn):** DEG/LAP of the source and its DRIFT (residual in sd against the set's value). Pit-loss drift is not shown per source.
- **B:** one column per unit (DEG/LAP, worst-corner wear per lap, pit loss) each with its drift; the full panel grows to about 96 cells.
- **C:** a selector above the table (`deg | wear | pit loss`) that switches the value and drift columns; one more window-local control.

Recommendation: A. Degradation is what changes with the car and the driver, so it is the drift worth watching; wear and pit loss stay visible in the values table.

### Q2. How are the override fields laid out?

Every value in the values table can be overridden (one uiAction per commit, C73). With per-corner wear that is seven fields per compound.

- **A (drawn):** a row of fields (`ovr`) under each compound row, one field under each value; 2 rows per compound.
- **B:** one row per priors key (`M deg/lap`, `M wear FL` …) with SET, N and a field column; about 26 rows, easy to read, long.
- **C:** no visible fields: a click on a value opens a field in its place; an overridden value is marked. Compact, but an override is visible only by its mark.

Recommendation: A. Every override is visible at a glance next to the value it replaces, and the table stays 7 rows.

**Answer:**

### Q3. Do the set's own values carry ᶜ inside the panel?

Spec 4.4 marks every value that rests on calibration with `ᶜ`. In the calibration panel every value is the set's.

- **A (drawn):** no `ᶜ` in the panel; only `ᵈ` where no source covers a value (soft, hard, SC).
- **B:** `ᶜ` on every calibration value in the panel too, as everywhere else.

Recommendation: A. A mark on every value says nothing; the mark that matters here is where the set has no data.

**Answer:**

### Q4. How is a missing source marked?

A missing source stays in the set and is left out of every value (spec 3.1). It is wrong, but not urgent.

- **A (drawn):** the row faint, the word `missing` in amber (warning), also in the prompt (`1 missing`).
- **B:** the row faint, `missing` grey: no colour.
- **C:** `missing` in red (critical).

Recommendation: A. Amber says "something to fix" without competing with the race's red alarms.

**Answer:**

### Q5. Which form does the top-bar segment take?

The segment names the active set (or `defaults`) and opens the prompt on a click.

- **A (drawn):** `calibration league`: a grey label and the name.
- **B:** `ᶜ league`: the badge glyph as the label; short, but the superscript is small.
- **C:** `league`: the name alone; it can be mistaken for the workbook name at the left.

Recommendation: A. The top bar has room, and the label leaves no doubt.

### Q6. Does the prompt open when the track has no set?

Without a set the run starts on the track file's defaults (spec 3.3), and the only choice in the prompt would be `defaults`.

- **A (not drawn: nothing to draw):** no prompt; the top bar shows `calibration defaults`.
- **B:** the prompt opens with `defaults` alone, as a reminder that no calibration exists for the track.

Recommendation: A. A prompt with one choice is a click for nothing; the top bar already says it.

**Answer:**

### Q7. Is a large drift highlighted?

DRIFT is the residual in sd. A source far from the set (old car spec, a wet stint) is what the user wants to spot.

- **A (drawn):** always grey.
- **B:** amber above a threshold (for example 2 sd); needs a config key and a field in `calibration.values` saying the source drifts, since the display may not judge (C43, C65).

Recommendation: B. It is the one thing in the sources table worth a glance during a weekend, and the cost is one config key and one flag.

**Answer:**

### Q8. Does the prompt close itself at lights out?

A pick on the grid or in the formation lap counts like any other (spec 3.3); an open prompt during the race covers the layout.

- **A (drawn):** it stays open until a choice, Esc or a click outside.
- **B:** it closes at lights out (session phase racing), keeping the preselection; `calibration.pick` still opens it.

Recommendation: B. The race start is the worst moment for an overlay, and closing keeps the safe choice.
