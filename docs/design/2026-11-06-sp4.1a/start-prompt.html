Session-start prompt and top-bar set name (SP4.1a §3.3)

A new session starts (the league race at Silverstone, on the grid). The UI opens the prompt over the window: the track's sets, the preselection marked, and defaults. Each row is a command (calibration.choose.<setId>, calibration.choose.defaults, C72); Enter sends calibration.choose. Esc, or a click outside, keeps the preselection. calibration.pick (the top-bar segment) opens it again at any time. The layout behind is dimmed here only to show the overlay.
