SP4.2 · pit-window-strip (new display, pitWindow.car)

The pit window of one of our cars, from now to the flag. Sample: Silverstone, 52 laps, KUH on mediums. now = the fitted set and the lap it reaches its life (tyre-life). Below it one row per available dry set that meets the compound rule (KUH started on M, so the second M set is left out): the window from its earliest lap (the first lap from which that set reaches the flag) to the fitted set's latest. A set that cannot reach the flag even from the latest lap says two stops; choosing between one stop and two is 4.3's. Numbers only, no verdict. Colour: white bold = the window is open now; amber = the fitted set is past its life. Compound letters grey (SP3).
