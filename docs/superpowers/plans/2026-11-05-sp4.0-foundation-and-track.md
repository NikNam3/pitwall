# SP4.0 Foundation and Track Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this repo every task has two phases by two agents (contract C82): a test agent writes the failing tests and commits them, an implementation agent makes them pass without touching them. Supervisor steps (marked **supervisor**) commit the contract, contract-first types (C81), data files and gates, and write no logic.

**Goal:** Every track of the 2025 season has a committed track file that units read as `view.track`, and on it the track map, official turns in the incident feed and the talk indicator in the top bar exist.

**Architecture:** Track data is reference data made once per track by a separate Python repo from FastF1 and committed as `data/tracks/<trackId>.json` (new clause C62b). The bridge loads the session's file at session start, writes it as a sidecar, and hands its `TrackData` to the scheduler as `view.track`. A pure shared helper `track-lookup` turns lap distances into lap fractions, map points, turns and braking-zone states; `track-positions`, `incidents` and `talk-window` use it; the `track-map` widget hands everything to a kit canvas that lays it out.

**Tech Stack:** TypeScript (Node type stripping), pnpm monorepo, vitest + fast-check, Svelte 5; Python 3 + FastF1 in the aux repo.

**Spec:** `docs/superpowers/specs/2026-11-05-sp4a/02-sp4.0-foundation-and-track-design.md` (approved by the user, 2026-11-05, with the user's contract review fixes 7ce689f). The contract `docs/architecture.md`; answers A1–A19 in `docs/superpowers/specs/2026-11-05-sp4a/00-carry-over.md` §9.

## Review Focus

1. **A car before the line on the grid** has a negative lap distance (and one just past the line can read more than the track length): its fraction wraps into `[0, 1)` and it is drawn near the line, never off the outline. → Task 5 row 2, Task 7 row 3.
2. **No track length yet** (`trackLengthM` 0 before the first Session packet): `fractionOf` gives `undefined`, the map leaves the car off and the talk indicator is `insufficientData`, never `NaN`. → Task 5 row 3, Task 7 row 4, Task 9 row 6.
3. **A braking zone just after the line** (turn 1 at most tracks): a car on the last metres of the lap sees it `ahead`, and a zone that wraps past the line is `inside` on both sides of it. → Task 5 rows 9–10, Task 9 row 3.
4. **A replay of a recording whose sidecar belongs to another track or fails validation** (a sidecar copied by hand, or one an older validator accepted): the sidecar fails validation at load, so `view.track` is `notApplicable` with one warning (C62b); the committed file is never used in its place. → Task 4 rows 5 and 6.
5. **A flashback after an incident marker appeared**: the markers after the rewind equal a run that never received the undone frames (C33). → Task 8 row 7.
