## Q1. A simulator calling another simulator (contract gap, C50)

**What:** `race-forecast` (simulator) calls `lap-model`'s `lapTimeMs` (simulator) for every car's lap. C50 says: "Only analyses and job modules call it." The high-level spec (§3, §6.2/§6.3) designed `race-forecast` on top of `lap-model`, so the code follows the design and the contract does not allow it.

- **A (recommended):** amend C50 to "Only analyses, job modules and other simulators call it", with an ADR 0015 line (a forecast is built from a lap model; a simulator composing another stays pure and unscheduled). No code changes.
- **B:** `lap-model` stops being a simulator: its `lapTimeMs` moves to `packages/analysis/src/shared/lap-model/` as a pure helper; `race-forecast` stays the one simulator. A code move, no contract change, but the spec's unit list changes.
- **C:** `lap-model` merges into `race-forecast`. Loses the separately tested lap model.
