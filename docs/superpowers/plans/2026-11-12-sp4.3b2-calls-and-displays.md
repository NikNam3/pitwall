# SP4.3b2 Calls and Displays Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this repo every task has two phases by two agents (contract C82): a test agent writes the failing tests and commits them, an implementation agent makes them pass without touching them. Supervisor steps (marked **supervisor**) commit contract-first types (C81), stubs, mechanical ports and gates, and write no logic; a minor change (C82) is the supervisor's in one commit.

**Goal:** The three race calls on the 4.3b1 decision engine (`undercut`, `pit-sweep`, `sc-call` as a job), the strategy table, undercut card, pit sweep table and SC card change in the `strategy` workbook for both our cars, the drivers panel and the preferred calibration set in the garage, the shell without the session-start prompt; then the SP4.3b gates and the merge to main.

**Architecture:** Each call is an analysis with a small Monte Carlo job (C51): `prepare` builds `strategy`'s input (moved to `analysis/src/shared/strategy-input/`) plus the call's own reads; `run` forces the call's stops, takes the continuation from `strategy-dp`'s new `bestWith`, and scores every case on common scenarios with `race-monte-carlo`'s new `scoreCalls`, under a scenario-policy cap (a count, never a clock). Job outputs are keyed by our cars; `bindJob` gains a `select` so every call topic is per car. Displays render topic values only (C65), with the distribution strip as one kit piece.

**Tech Stack:** TypeScript (Node type stripping), pnpm monorepo, vitest + fast-check, worker threads (the existing job runtime), Svelte 5, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-12-sp4.3b-decisions-under-uncertainty-design.md` §9, §10, §11, §12 (with the mockup fixes of 12c23611). Mockups (approved, Q1–Q10 answered): `docs/design/2026-11-12-sp4.3b/` (`README.md`, `strategy-table-b.html`, `undercut-card.html`, `pit-sweep-table.html`, `sc-card.html`, `drivers-panel.html`, `calibration-panel.html`, `strategy-workbook.html`; `gen.mjs` draws them and holds the sample numbers). It builds on the 4.3b1 plan `docs/superpowers/plans/2026-11-12-sp4.3b1-decision-engine.md`, whose Task 3 and Tasks 17–20 define the names used here.

**Clauses:** C2, C14, C30, C41, C43, C44, C49, C51, C56. **Unit:** `undercut`. After Tasks 4–6.

**Interfaces:**
